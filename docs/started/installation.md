
# Installation

Here is a video tutorial on how to [Install Hello2Forms](https://www.youtube.com/watch?v=BNajDKj56fA)
if this is your cup of tea :D. Otherwise, you can follow the instructions below.

## Install using the WordPress Admin

1. Download the plugin file from CodeCanyon.
2. Log in to your WordPress admin dashboard.
3. Navigate to **Plugins > Add New**.
4. Select the **Upload Plugin** button.
5. Choose the `hello2forms.zip` file from your computer and click **Install Now**.
6. Once the installation is complete, click **Activate**.
7. Once activated, you can access the plugin settings from the left-hand menu.


## Install using FTP (Recommended for slow internet connections)

1. Download the plugin file from CodeCanyon.
2. Extract the downloaded file to your computer.
3. Using an FTP client, connect to your web server and navigate to the `/wp-content/plugins/` directory.
4. Upload the extracted `hello2forms` folder to the `/wp-content/plugins/` directory on your server.
5. Log in to your WordPress admin dashboard.
6. Navigate to **Plugins** and activate the Hello2Forms plugin.
7. Once activated, you can access the plugin settings from the left-hand menu.

If you have any issues during the installation process, please [contact support](mailto:support@clinicsoftware.com) for assistance.

If everything went well, you can now proceed to the configuration section to set up your first form.
