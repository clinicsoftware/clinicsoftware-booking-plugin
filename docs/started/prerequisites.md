# Prerequisites

Before you start, you need to have the following:
- A domain name.
- A web server with PHP and MySQL installed.
- A working WordPress installation.
- A user account with administrator privileges.

The webserver must meet the following requirements:
- PHP 8.1 or newer.
- MySQL 8.0.13 or newer or MariaDB 10.1 or newer. Make sure the database supports [Explicit Default Values](https://dev.mysql.com/doc/refman/8.0/en/data-type-defaults.html#data-type-defaults.html#data-type-defaults-explicit).

Proceed with the installation only if you have the above requirements met.
